# ByteSpace

A modern, responsive online learning platform built with **Next.js (App Router)**, **TypeScript**, and **Tailwind CSS**. Browse courses, watch video previews, and explore detailed course pages with About, Lessons, and Reviews tabs.

## Getting Started

### Prerequisites

- **Node.js**
- **npm** (comes with Node.js)
- **Git**

### Installation

```bash
# 1. Clone the repository
git clone https://github.com/tonmoy-sutradhar/ByteSpace_project.git

# 2. Go into the project folder
cd ByteSpace_project

# 3. Install dependencies
npm install

# 4. Start the development server
npm run dev
```

Open **http://localhost:3000** in your browser. That's it.

### Available Scripts

| Command         | Description                                  |
| --------------- | -------------------------------------------- |
| `npm run dev`   | Start the development server with hot reload |
| `npm run build` | Create an optimized production build         |
| `npm run start` | Run the production build locally             |

## Deployment

This project is deployed on **Vercel**.

To deploy your own copy:

1. Push the repository to GitHub.
2. Go to [vercel.com/new](https://vercel.com/new) and import the repository.
3. Click **Deploy**. Vercel detects Next.js automatically, so no extra configuration is needed.
